# Changelog

## 2.1.0 — Financial dashboard release

- Added income records with separate local JSON persistence.
- Added total income, total expenses, current balance and current-month expense metrics.
- Added a six-month income-versus-expense bar chart.
- Added a current-month expense category donut chart.
- Added unified transaction history for income and expenses.
- Added type, category, search and date-range filters.
- Added CSV export with UTF-8 BOM for common spreadsheet applications.
- Added GitHub Actions Windows UCRT64 build workflow and manual test plan.
- Kept Version 1 expense JSON compatible.

## 2.0.0 — Expense tracker foundation

- Added Qt 6 Widgets desktop interface.
- Added expense creation, editing, deletion, search and filters.
- Added JSON expense storage.
